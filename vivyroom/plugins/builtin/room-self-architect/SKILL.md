# Room Self-Architect Skill (Antigravity-Grade Self-Modification)

1. Inspect `Vivyroom`'s own directory structure, Python AST health, and UI assets.
2. Verify explicit user permission (`UserPermissionGate` + Rust `vh_record_room_mutation`).
3. Create an automatic backup in `.vivyroom_snapshots/` before touching any file.
4. Apply surgical edits or theme/layout updates, verify AST syntax, and trigger live UI hot-reload.
